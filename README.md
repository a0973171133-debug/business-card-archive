# 名片自動歸檔

這是建築師／業主名片自動歸檔專案，包含：

- `網頁版/index.html`：名片資料庫網頁版
- `名片資料庫.json`：權威資料庫
- `名片資料庫.xlsx`：Excel 資料庫
- `照片/建築師/已歸檔/`、`照片/業主/已歸檔/`：已歸檔名片照片
- `名片自動歸檔.mjs`：原始照片歸檔程序
- `更新名片資料庫.mjs`：更新 Excel 資料庫程序

## 網頁版使用

開啟 `網頁版/index.html` 即可使用搜尋、分類、詳細資料、照片預覽、JSON 匯入／匯出與 CSV 匯出功能。

網頁版新增或編輯的資料會先保存在瀏覽器本機；若要同步回專案資料庫，請匯出 JSON 後再依專案歸檔流程處理。

## 隱私

本 Repository 設為 Private，因為資料包含名片姓名、電話、傳真、Email 與照片。
